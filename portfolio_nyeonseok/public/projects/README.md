# 프로젝트 이미지 폴더

이미지를 폴더에 넣기만 하면 사이트에 나타납니다. 코드는 고치지 않아도 됩니다.
비어 있는 폴더는 화면에서 자동으로 숨겨지므로, 아직 이미지가 없어도 레이아웃은 깨지지 않습니다.

```text
public/projects/<프로젝트>/<폴더>/<파일>
```

## 규칙

- **순서**: 파일 이름 순서대로 보입니다. `01-main.webp`, `02-login.webp`처럼 숫자를 앞에 붙이세요.
- **형식**: `webp` 권장 (`png`, `jpg`, `avif`, `gif`, `svg`도 됩니다). 영상은 `mp4`, `webm`.
- **크기**: 가로 1600px 이하로 줄여서 넣으세요. 원본 스크린샷(수 MB)을 그대로 넣으면 페이지가 느려집니다.
- **cover/**: 첫 번째 이미지가 프로젝트 목록 카드와 상세 페이지 상단에 쓰입니다. 실제 서비스 화면을 권장합니다.
- **영상 포스터**: `04-demo.mp4` 옆에 `04-demo.poster.webp`를 두면 재생 전 대표 화면으로 쓰이고,
  영상은 재생 버튼을 누르기 전까지 내려받지 않습니다. 포스터 이미지는 목록에 따로 나오지 않습니다.
- **캡션**: `src/data/projects/<프로젝트>.ts`의 `captions`에 `'폴더/파일명': '설명'` 형식으로 적으면
  이미지 아래 캡션과 대체 텍스트(alt)로 함께 쓰입니다. 적지 않으면 "프로젝트명 + 폴더 이름 + 번호"가 alt가 됩니다.

```ts
captions: {
  'screens/01-main.webp': '메인 화면 — 문제 사진 업로드',
},
```

## 폴더가 보이는 위치

각 프로젝트 데이터 파일의 `media` 항목이 폴더와 위치를 연결합니다.

| placement | 상세 페이지 위치 |
|---|---|
| `screens` | 서비스 화면 섹션 |
| `cases` | 문제 해결 섹션 끝 |
| `results` | 결과 섹션 |
| `flow` | Architecture · Flow 섹션 |

문제 해결 사례 하나에 붙는 폴더(예: Projectree `performance/`)는 그 사례의 `media`에 지정되어 있습니다.
